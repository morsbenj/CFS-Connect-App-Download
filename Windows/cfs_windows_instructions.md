>    - Locate the downloaded ZIP file.
>    - Right-click and choose "Extract All..." or use your favorite extraction tool.

> ### Step 3
>
> **Rename the Package Folder and Move it to Somewhere Safer:**
>    - Right click on the unzipped folder called 'Release'
>    - Rename it to something that makes sense like 'cfs_app'
>> <img width="490" height="101" alt="image" src="https://github.com/user-attachments/assets/0a604742-68d0-49f5-bc07-b2622b6fe574" />
>    - Cut and paste the renamed folder in a location that makes sense to store the app.
>       (I used "C:\Users\Admin\Documents\PortableApps")


> ### Step 4
> **Create the Shortcut for your Desktop to run the App With**
>    - Navigate the cfs_app folder in its new location and right click on the .exe file with the build number
>    - Create shortcut
>    - Rename the shortcut to the actual app name or something that make sense. e.g. 'CFS App' or 'CFS-Connect'
>> <img width="656" height="502" alt="image" src="https://github.com/user-attachments/assets/1691ee63-f458-47b8-99da-3e69df1281d1" />
>    - Click and drag the new shortcut to your desktop so it comes up easily when searched for.
>> <img width="790" height="150" alt="image" src="https://github.com/user-attachments/assets/821dfbdc-053d-45b5-a17b-30c48d344876" />
